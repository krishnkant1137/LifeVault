LifeVault – Secure Digital Legacy Management System

LifeVault is a secure, folder-based digital vault designed to manage and transfer sensitive personal information in a controlled and verified manner.

Key Features

Secure storage for documents, passwords, media, and personal messages

Nominee-based access with verification triggers (death / time-based)

Role-based access control (Owner, Nominee, Admin)

Read-only access for nominees after approval

Encryption and audit logging

Inactivity reminders and nominee notifications

Tech Stack

Backend: Java, JDBC

Database: MySQL

Security: Encryption, Role-Based Access

Architecture: Layered (Controller, Service, DAO, Model)
